# 配置契约

> 本文档是**配置项与环境变量的唯一事实源**。启动逻辑、`.env.example` 与 `config/config.toml` 都向本契约对齐。
> 与"取消运行时降级"的定稿一致：缺失必填项时**直接启动失败**，不做任何兜底。

## 一、分层与优先级

从高到低：

```
环境变量  >  config/.env  >  config/config.toml  >  代码内默认值
```

- **密钥只允许出现在 `config/.env` 与环境变量**，`config/config.toml` 只能放可公开的默认值。
- `config/config.toml` 与 `config/.env.example` 入库；`config/.env` 被 `.gitignore` 忽略，永不入库。
- 算法参数（阈值、权重、Top-K）一律放 `config.toml`，不放环境变量——可版本化、可评审、可随代码一起回溯。

## 二、环境变量总表

### 2.1 必填项（缺失或非法即启动失败）

| 变量 | 类型 | 校验规则 | 缺失时的行为 |
| --- | --- | --- | --- |
| `DEEPSEEK_API_KEY` | string | 非空、去掉首尾空白后长度 > 0 | 打印 `E_CONFIG_MISSING: DEEPSEEK_API_KEY`，退出码 2 |
| `DASHSCOPE_API_KEY` | string | 启用多模态打标或向量召回时非空 | 打印 `E_CONFIG_MISSING: DASHSCOPE_API_KEY`，退出码 2 |
| `DATABASE_URL` | DSN | 必须以 `postgresql+asyncpg://` 开头 | 打印 `E_CONFIG_MISSING` 或 `E_CONFIG_INVALID`，退出码 2 |
| `REDIS_URL` | DSN | 必须以 `redis://` 或 `rediss://` 开头 | 同上 |

`DASHSCOPE_API_KEY` 是**辅助服务密钥**，同时承担两个用途：素材抽帧打标（多模态）与文本向量化（embedding）。两个能力的服务端点由 `[vision].base_url` 与 `[embedding].base_url` 分别配置，因此可以指向**任意 OpenAI 兼容的服务商**（默认阿里云百炼）；变量名本身也可由 `[vision].api_key_env` / `[embedding].api_key_env` 改写。换供应商属于配置变更，不需要改代码。

### 2.1.1 必填项分级生效

必填项**不是从第一天起就全部要求**，按阶段与能力分级：

| 变量 | 从哪个阶段起必填 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | P1 | 文本模型：线索拆解与撰稿 |
| `DATABASE_URL` | P2 | 数据库建立之后 |
| `DASHSCOPE_API_KEY` | 按能力 | **仅当**多模态打标或向量召回启用时必填（`[vision].enabled` / `[embedding].enabled`）；两者都未启用则不要求 |

前置检查只校验**当前阶段**的必填项（P1 阶段只要求 `DEEPSEEK_API_KEY`）：未到阶段性要求的变量即使缺失也不阻断启动，也不会校验其格式。
| `REDIS_URL` | P3 | 队列与缓存建立之后 |

未启用的能力不要求其密钥，也不影响启动。这属于**能力裁剪**，不属于运行降级——降级的定义是"依赖本应可用却静默改用劣质路径"，与 `AGENTS.md` 第 4 节的边界一致。

### 2.2 可选项

| 变量 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `LANGFUSE_PUBLIC_KEY` | string | 空 | 调用追踪公钥 |
| `LANGFUSE_SECRET_KEY` | string | 空 | 调用追踪私钥 |
| `LANGFUSE_HOST` | URL | 空 | 追踪服务地址 |
| `XHS_LLM_PROVIDER` | enum | `openai_compatible` | 覆盖 `[llm].provider`；合法值同 §3.1，`auto` 与 `offline` 已取消 |
| `XHS_LLM_BASE_URL` | URL | 空 | 覆盖 `[llm].base_url` |
| `XHS_LLM_MODEL` | string | 空 | 覆盖 `[llm].model` |
| `XHS_LLM_API_KEY` | string | 空 | 覆盖文本模型密钥 |
| `XHS_EMBEDDING_MODEL` | string | 空 | 覆盖 `[embedding].model` |
| `XHS_CONFIG_PATH` | path | `config/config.toml` | 指定配置文件位置 |
| `XHS_LOG_LEVEL` | enum | `INFO` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |

**可观测三件套的处理方式**：`LANGFUSE_*` 三者齐全时启用调用追踪；不齐时**关闭追踪并打印一条 warning**。可观测属于旁路组件，关闭它不影响分析结果的正确性，因此不属于"运行链路降级"。

## 三、config.toml 段结构

字段、默认值与取值范围由启动前置检查第 2 步校验（见第四节）。**未知段或未知字段一律视为配置错误**（退出码 2）——拼错的字段必须当场报错，不能静默忽略。密钥一律不写在本文件里（见第一节）。

### 3.1 `[llm]` 文本模型

| 字段 | 默认值 | 取值范围 / 规则 |
| --- | --- | --- |
| `provider` | `openai_compatible` | `openai_compatible`、`openai`、`deepseek`、`qwen`、`dashscope`、`compatible`（都走 OpenAI 兼容端点）；`auto` 与 `offline` 的降级语义已取消 |
| `base_url` | `https://api.deepseek.com/v1` | 非空字符串 |
| `model` | `deepseek-flash` | 非空字符串 |
| `api_key_env` | `DEEPSEEK_API_KEY` | 非空字符串；密钥只写 `config/.env` 或环境变量 |
| `temperature` | `0.6` | 0–2 |
| `max_tokens` | `2000` | 1–32768 |
| `timeout_s` | `60` | 1–600 |
| `max_retries` | `2` | 0–10 |
| `price_in_per_m` | `2.16` | ≥ 0；人民币元/百万 token，仅用于成本估算 |
| `price_out_per_m` | `8.64` | ≥ 0；人民币元/百万 token，仅用于成本估算 |

### 3.2 `[vision]` 多模态打标

| 字段 | 默认值 | 取值范围 / 规则 |
| --- | --- | --- |
| `enabled` | `false` | 布尔；置为 `true` 即要求 `api_key_env` 指向的密钥（见 §2.1.1） |
| `base_url` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 非空字符串 |
| `model` | `qwen-vl-max` | 非空字符串 |
| `api_key_env` | `DASHSCOPE_API_KEY` | 非空字符串 |
| `max_frames` | `3` | 1–10 |
| `max_width` | `720` | 64–4096 |

### 3.3 `[embedding]` 文本向量化

| 字段 | 默认值 | 取值范围 / 规则 |
| --- | --- | --- |
| `enabled` | `true` | 布尔；向量召回是产品主线，默认启用。置为 `true` 即要求 `api_key_env` 指向的密钥（见 §2.1.1） |
| `base_url` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 非空字符串 |

| 键 | 默认值 | 说明 |

## 四、启动前置检查（preflight）

按顺序执行，任一步失败即中止启动：

| 步骤 | 检查内容 | 失败行为 | 退出码 |
| --- | --- | --- | --- |
| 1 | 必填环境变量齐全且格式合法（按 §2.1.1 分级生效） | 打印缺失项与格式错误清单 | 2 |
| 2 | `config.toml` 可解析、字段类型与取值在允许范围内 | 打印出错的段与字段 | 2 |
| 3 | 数据库可连接 | 打印连接串（脱敏）与底层错误 | 3 |
| 4 | 数据库扩展 `vector` 与 `pg_trgm` 已安装，pgvector ≥ 0.5.0 | 打印当前版本与安装提示 | 3 |
| 5 | 数据库迁移版本处于最新（Alembic head） | 打印当前版本与期望版本，提示执行迁移 | 3 |
| 6 | Redis 可连接（`PING`） | 打印连接串（脱敏）与底层错误 | 3 |
| 7 | `[frontend].serve = true` 时 `frontend/dist` 存在且非空 | 打印期望路径与构建命令 | 2 |

**模型服务不在启动时探测**：启动即调用模型会产生实际费用，也可能因网络抖动误判。模型可用性由 `GET /api/health` 按需探测，结果不计入启动成败。

退出码约定：`2` = 配置错误，`3` = 依赖不可用。两者都必须给出**可直接照做的修复提示**，而不是只吐一个堆栈。

## 五、前端与静态资源

前端是 **Vue 3 + Vite + TypeScript 单页应用**（ADR 0008），与 API 同源部署（ADR 0009）：

| 项 | 约定 |
| --- | --- |
| 构建产物 | `frontend/dist/`，不入库，由多阶段 Docker 镜像在构建阶段生成 |
| 生产挂载 | FastAPI 把 `frontend/dist` 挂在根路径；非 `/api` 且未命中静态资源时回落到 `index.html`，交给前端路由 |
| 开发模式 | Vite dev server（默认 `http://localhost:5173`）提供前端，并把 `/api` 代理到 `http://localhost:8000` |
| 接口地址 | 前端读取 `VITE_API_BASE_URL`，默认 `/api`，开发与生产无需改代码 |
| 类型来源 | `openapi-typescript` 从 `docs/contracts/openapi.yaml` 生成 `frontend/src/api/schema.d.ts`，生成物入库 |
| 工具链版本 | Node 25.3.0；包管理器 pnpm 11.25.0；`pnpm-lock.yaml` 入库 |

`[frontend].serve = true`（生产默认）时，`dist_dir` 缺失或为空即**启动失败**（退出码 2）；开发模式设为 `false` 可只跑 API。

## 六、脱敏与日志

- 启动时打印一份**脱敏配置摘要**：密钥统一显示为 `***`（不显示长度与前后缀），DSN 隐去密码部分。
- 禁止把密钥写入日志、报告、数据库或 `runs/` 下的任何产物。
- `load_config` 对应的公开接口只返回 `has_key` 之类的布尔值，不返回密钥本身。

## 七、变更规则

1. 本契约是唯一事实源；新增或修改配置项必须同时更新：本文件、`config/.env.example`、`config/config.toml`（若属可公开默认值）、preflight 清单。
2. 新增必填项属于**破坏性变更**，必须在 `docs/adr/` 补一条 ADR 说明迁移方式（老用户如何补齐）。
3. 密钥轮换不属于契约变更，只需替换 `config/.env`，无需改代码或文档。
