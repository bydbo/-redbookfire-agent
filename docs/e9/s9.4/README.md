# S9.4 真人试用执行包（模板，不招募）

> 状态：模板已落盘，**未招募、未发送邀请、未开展试用**。S9.4 的前置是 S9.3 完成和
> S11.1 完成；E9 的 10 元预算不自动用于本阶段。
>
> 目标：3–5 位有真实需求的参与者，至少 15 个真实任务；记录素材与文案的**实际采纳**，
> 不要求正面评价。个人自测不能补足人数，样本不足保持未完成。

## 文件

| 文件 | 用途 |
|---|---|
| `consent.md` | 试用说明与同意记录 |
| `session-guide.md` | 主持脚本、任务表、人工 / 系统耗时记录 |
| `adoption.csv` | 每任务素材与文案采纳表 |
| `failure-log.csv` | 失败、退出与清理记录 |
| `summary-template.md` | 脱敏汇总报告模板 |

## 执行顺序

1. 确认 S11.1 本地部署边界和 S9.3 报告；准备受控本地单用户演示环境。
2. 用户协调参与者；先签同意记录，再分配任务。不要收集无关个人信息。
3. 人工检索与系统辅助使用相同任务目标和素材库；预先交叉分配顺序，记录熟悉度和学习效应。
4. 每个任务记录：找素材耗时、可用素材、实际采用项、初稿、最终稿、修改耗时、弃用和失败原因。
5. “觉得不错”“愿意采用”“实际用于任务”“已经发布”分开记录，不合并成一个满意度。
6. 文案修改量用字符编辑距离 + 人工分类；完全重写、弃用、无初稿单列。
7. 结束当天完成脱敏和清理；原始截图、聊天和个人信息留在忽略目录，汇总只写编号。

## 禁止

- 把演示脚本、预制结果或 agent 自测包装成真人采纳；
- 用“愿意采用”代替“实际用于任务”；
- 为凑样本让同一人重复计数；
- 在公开网络暴露参与者身份、素材原文件或未脱敏对话。
