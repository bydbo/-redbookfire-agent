# 主持脚本与任务表（模板）

## 开场（2 分钟）

- 说明这是本地单用户演示，不是公开产品；允许随时停止。
- 说明我们记录的是任务耗时、实际采用项和失败原因，不是对人的评价。
- 确认同意记录已签；确认素材使用范围。

## 任务流程

1. 主持人读出任务目标，不提示系统答案，不替参与者操作。
2. 参与者先用**人工方式**在同一素材库找素材，记录起止时间与找到的素材。
3. 再用系统辅助完成同一目标；记录首次结果、追问 / 改稿和最终稿。
4. 主持人只做中性提示（“你可以继续”“请按你真实会用的方式”），不引导正面评价。
5. 每个任务结束立即填写 `adoption.csv` 和 `failure-log.csv`；不凭记忆补记。

## 收尾（3 分钟）

- 询问“今天有没有哪一步让你想放弃”，记录原话（脱敏）。
- 确认是否保留素材 / 文案；需要删除的按退出流程处理。
- 不现场承诺发布效果或后续商业合作。
