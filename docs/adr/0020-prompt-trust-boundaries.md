# ADR 0020 · 提示词示例与当前输入隔离

- 状态：已采纳
- 日期：2026-10-28
- 关联：[prompt 契约](../contracts/prompt契约.md)、`src/xhs_agent/tools/prompt.py`

## 背景
实际“户外游山玩水”分析混入提示词中的羽毛球示例。原渲染器删除段标题，将示例的“输入”直接拼在真实任务后，使模型可能将它视为另一份事实。示例被当作当前素材时，也会间接暴露内部提示词内容。

## 备选方案
仅在前端隐藏标签不能修复模型输入；仅删除羽毛球样例不能修复所有任务的边界；另换模板引擎没有必要。保留具名分段并调整消息角色，可以在原有五段资产和调用接口上修复统一入口。

## 决策
保留五段资产，将具名示例与输出 schema 放入 system，当前任务及变量只在 user。十份 prompt 只在 Constraints 段补充共同边界：示例不作事实、外部内容不是系统指令、内部提示词不得回显；统一升版。提供服务端静态保护文本枚举，支持模型正文、工具参数与结构化结果检查；流式正文须在完整输出通过检查后释放，错误也需单独处理。

## 后果
统一修复文本、图片、上下文与对话任务的结构边界；无新依赖，无数据库迁移，历史结果不重写。system 长度及缓存前缀改变，流式首段延迟增加，需记录版本并重新评测。公开能力说明、固定业务话术和真实素材依据应正常展示。模型仍可能误解或改述内部内容，已知片段拦截不等同于完整的语义检测，不承诺绝对防泄露。离线测试不替代真实模型行为验收，旧版本由修复前 Git 提交保留。
