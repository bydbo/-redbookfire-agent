## 3. 执行协议

- **两臂**：基线（`cbd13f9` 代码 + `mode=off`）与候选（当前 HEAD + `mode=enforce`）。
  输入、素材快照、模型参数与评分规则完全一致。
- **重复**：每臂每模板 3 次 → 72 条执行会话、至少 648 轮。
- **前缀实验**：至少 30 组 × 3 次请求（≥90 次），同模型同参数固定前缀，报告实际分项。
- **评分**：字数、版本、引用、调用次数用确定性规则；语义约束匿名人工核对；
  **禁止模型评委或开发 agent 自评充当人工判定**。
- **成本**：首轮规划上限 200 元；未获授权不执行。每轮 0.25 元门槛保留（含抽取与修复调用）。
- **分母**：失败 / 超时 / 空输出保留在任务成功率分母；应澄清 / 停止的场景按正确处理判成功。

## 4. 硬门槛（与方案 §4.4 一致，不放宽）

- 必需事实保留、旧约束排除、来源、版本绑定、冲突保护、预算覆盖、缓存正确、固定集复算：**100%**。
- 跨会话泄漏、静默丢约束、孤立工具结果、估算超限仍发送、错误基础提交、缓存重复计费：**0 次**。

- 200 次状态读取+装配 P95 ≤100ms；100 次缓存查询 P95 ≤100ms。
